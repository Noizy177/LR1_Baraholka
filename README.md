# Интернет-барахолка

Учебный многостраничный сайт интернет-барахолки, разработанный в рамках лабораторной работы №2 по Web-программированию.

Сайт был реализован по предоставленным макетам, в условиях чего имеет не все функциональные страницы, которые можно видеть на экране.
## Основные возможности

- просмотр категорий товаров;
- каталог с фильтрацией и сортировкой;
- отдельная страница товара;
- добавление товаров в корзину;
- оформление заказа;
- ввод контактных данных и адреса;
- выбор доставки или самовывоза для каждого продавца;
- выбор способа оплаты;
- форма подписки;

P.S. (данные на страницах жестко привязаны в рамках верстки макета без реального функционала)

## Страницы проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница отдельного товара;
- `cart.html` — корзина;
- `checkout.html` — оформление заказа.

## Используемые технологии

Проект выполнен с использованием HTML5 и CSS3.

В разметке применяются семантические элементы HTML5, формы и встроенная проверка полей ввода.

Для оформления используются:

- Flexbox;
- CSS Grid;
- Media Queries;
- CSS Transitions;
- CSS Transform;
- SVG-иконки.


## Адаптивность

Интерфейс адаптирован для мобильных устройств, планшетов, ноутбуков и больших мониторов.

Основные контрольные размеры:

- 320 px — мобильные устройства;
- 768 px — планшеты;
- 1000 px — десктопы и планшеты в альбомной ориентации;
- 1280 px и более — большие экраны.
